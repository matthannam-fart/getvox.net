# getvox.net

Splash page for [Vox](https://github.com/matthannam-fart/vox), an intercom for your computer.

Hosted on GitHub Pages with a custom domain (`getvox.net`) registered through Namecheap.

## Files

- `index.html` — the splash page (single file, inline CSS)
- `vox_logo.png` — the Vox wordmark
- `CNAME` — tells GitHub Pages which custom domain to serve

## Deploying changes

Edit `index.html`, commit, and push. GitHub Pages rebuilds automatically.

```sh
git add .
git commit -m "Update splash"
git push
```
